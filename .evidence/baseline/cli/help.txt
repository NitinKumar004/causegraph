usage: cg [-h] {tree,path,why,load} ...

CauseGraph — trace why a process exists.

positional arguments:
  {tree,path,why,load}
    tree                print a process and its descendants
    path                print the root-ward ancestry path to a process
    why                 explain why a process is hot/using resources
    load                seed a database from an events JSONL file (dev helper)

options:
  -h, --help            show this help message and exit
